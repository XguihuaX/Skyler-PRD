# F-008 · ComfyUI 独立连接器

| 项目 | 内容 |
|---|---|
| 状态 | 独立连接层已实现 · Reviewer Round 5 PASS · 待负责人验收 |
| 适用范围 | 独立基础设施，暂不暴露给角色自动调用 |
| 并行关系 | 可与 F-001、F-002、F-006 并行 |

## 1. 产品目标

建立可独立测试的 ComfyUI 后端连接器，未来供用户显式生成图片和角色自动分享策略复用。第一版只解决连接协议和稳定请求/结果契约，不改变聊天、日常代理、状态机或界面行为。

## 2. 第一版必须支持

- 健康检查；
- 按已注册工作流编号提交任务；
- 通过结构化语义参数注入工作流；
- 查询队列和任务状态；
- 等待完成与超时；
- 返回输出图片元数据；
- 安全取消仍在排队的任务；
- 对未配置、连接失败、超时、工作流错误和输出缺失返回稳定错误结果；
- 使用模拟传输完成全部自动测试，不连接真实 ComfyUI。

## 3. 锁定边界

- 地址通过客户端构造参数注入，第一版不落盘、不修改 `config.yaml`；
- 工作流注册表通过只读映射注入，不读取用户私人工作流；
- 请求只能指定已注册工作流和白名单语义参数，不能上传任意工作流、节点编号、主机地址或输出路径；
- 第一版只返回 ComfyUI 输出元数据，不复制、保存或公开图片文件；
- 进度只报告真实的排队、运行、完成、失败等状态，不伪造百分比；
- 默认只取消排队任务，不调用可能影响共享实例的全局运行中断；
- 不新增依赖、数据库表、路由、能力工具或 `main.py` 注册；
- 不修改提示词、聊天主链、DailyAgent、FSM、亲密度或附件持久化。

## 4. 稳定契约

请求至少包含：请求编号、工作流编号、结构化输入和可选超时时间。

结果至少包含：请求编号、工作流编号、ComfyUI 任务编号、完成状态、输出元数据、稳定错误码、提交与完成时间。

错误码覆盖：未配置、连接失败、超时、工作流不存在、输入非法、提交被拒绝、工作流失败、输出缺失、已取消和协议错误。

错误信息不得泄露完整工作流、私人提示词、主机内部路径或输出内容。

## 5. 明确不做

- 角色自动触发；
- 用户显式调用能力和聊天工具注册；
- 图片聊天气泡和前端界面；
- 图片持久化、归属、保留期和删除策略；
- 私人工作流扫描；
- 真实服务联调或外部模型下载；
- 运行中任务的全局中断。

## 6. 后续自动调用依赖

F-001、F-002、F-006 只提供时间、日程和状态上下文。角色自动生成并分享图片还需要：

- 分享意图与触发策略；
- 用户许可、频率、冷却和计算成本限制；
- 工作流选择和角色视觉一致性；
- 提示词安全策略；
- 图片持久化、归属和聊天投递；
- 幂等与失败降级。

因此连接器完成后可以先支持未来的显式用户请求，但不能直接宣称角色会自主发图。

## 7. 验收标准

- 所有测试使用模拟传输，不发送真实网络请求；
- 健康、提交、排队、运行、完成、失败、超时和取消均有自动测试；
- 未知参数、错误类型和缺少必填项在提交前被拒绝；
- 工作流模板每次深拷贝，单次请求不会污染注册表；
- 单图、多图、空输出和畸形输出均能稳定归一化；
- 不新增任何角色可见工具、路由、数据库或提示词变化。
