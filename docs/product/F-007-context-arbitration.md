## 功能目标

F-007 分成两个连续判定器：先判断“当前应相信哪些证据”，再判断“这一轮最适合做什么”。Persona 只负责自然表达，不得推翻事实仲裁和动作判定。

## 第一、二阶段范围

- 使用统一证据信封保存来源、时间、有效期、范围、置信度、派生方式和可说性。
- 只对相同显式 `claim_key` 做自动冲突；不根据自由文本猜测语义冲突。
- 七种处置结果：`USE_CURRENT`、`USE_VERIFIED`、`COEXIST`、`IGNORE`、`HEDGE`、`VERIFY_WITH_TOOL`、`ASK_USER`。
- 事实权威按领域决定，不使用全局加权总分：用户当前自述主导用户事实，成功工具结果主导外部当前事实，当前结构化运行态主导角色当前事实。
- 用户信号按风险、边界、纠正、请求、问题、需要/价值、第一人称感受、问候、事实、模糊依次判定。
- 回复动作包括回答、接住、反映、澄清、追问、提供选项、执行、分享、自述、边界；每轮一个主动作，至多一个辅动作和一个问题。
- 第一、二阶段默认关闭主动分享、角色自述和心理假设；普通聊天保持单主模型调用。
- 生成前只注入不超过 1200 字的本轮判定卡，不复制 Persona、历史或记忆正文。
- 判定卡只约束用户发起的普通对话，不覆盖已有 proactive 触发器的主动行为契约。

## 未来需求：话题分层与按需多跳检索（未实现）

> 本节只记录后续设计方向，当前没有实现 Topic 数据结构、embedding、检索路由、RAG API、迁移或测试，也不改变 F-007 的现有状态和验收结论。

### 写入侧：先区分是否值得长期保存

- 临时、无关的普通问答只保留在短期原文窗口，不自动进入长期记忆或用户画像。
- 对需要跨轮次延续的对话按 Topic 切分；每个 Topic 保存话题标识、简短摘要、实体/关键词、时间范围、重要度、向量表示，以及指向原始 turn 的引用。
- 存储原始对话不代表每轮都把原文注入 Prompt；平时只使用当前话题和必要的短摘要，命中旧 Topic 后再判断是否需要局部展开。

### 检索门：先判断是否需要检索

每轮先路由到以下一种处理方式，而不是固定执行 Top-K 检索：

- `NO_RETRIEVAL`：普通问候或当前短期上下文已经足够。
- `MEMORY_RAG`：需要回忆跨 Conversation 的用户经历、偏好或既有讨论。
- `DOCUMENT_RAG`：问题依赖用户明确提供或授权的文档。
- `EXTERNAL_TOOL`：问题依赖实时或外部事实，应调用对应搜索/API，而不是从记忆中猜测。

### 粗到细的两阶段检索

1. **Hop 1 · Topic Summary 定位范围**：先检索话题摘要，确定候选 Topic、Conversation、时间范围和相关实体。摘要已经足以回答时立即停止，不展开原文。
2. **Hop 2 · Topic 内部寻找证据**：只有摘要证据不足、用户要求精确细节或原始措辞时，才在命中的 Topic 内展开相关原始对话、结构化记忆或文档块。
3. **Hop 3 · 关系补全**：只有答案仍缺少必要实体关系时才允许第三跳；默认最多两跳，复杂问题最多三跳。

因此，“话题切分”不是把所有 Topic 摘要和原文长期放入热上下文，而是先命中摘要，再按证据需要展开对应的一小段内容。

### 停止条件、安全边界与注入预算

- 每一跳必须缩小检索范围；若没有新增有效证据、相关性或置信度低于阈值、达到最大跳数、Token 预算或延迟预算，应立即停止。
- 维护已访问 Topic、memory、document 和 turn 的集合，禁止重复展开形成检索循环。
- 检索必须按用户、角色、Conversation、数据类型和权限隔离；不得跨越未授权的数据边界。
- 低置信度结果不得作为确定事实，无法取得可靠证据时应向用户澄清。
- 每条最终证据保留来源、时间和原始引用，使结论可追溯，并能在冲突时比较来源与新旧程度。
- 召回结果先经过过滤、重排、去重和压缩，最终只把少量高相关证据交给 Context Arbitration；保留原文不等于每轮注入原文。

### 可验收路由示例

| 用户输入 | 预期处理 |
|---|---|
| “你好” | `NO_RETRIEVAL`，不检索 |
| “刚才第二点是什么意思？” | 只读取短期上下文，不检索长期记忆 |
| “还记得我上次面试的结果吗？” | `MEMORY_RAG`，先命中相关 Topic Summary，必要时展开局部证据 |
| “根据我上传的简历总结经历” | `DOCUMENT_RAG`，只检索获授权的简历文档范围 |
| “今天英伟达股价是多少？” | `EXTERNAL_TOOL`，调用实时数据工具，不从记忆回答 |
