1. **低：明确版本引用的用途。** SPEC §3.3 首句仍写“首轮采用 MaiBot v1.4.7”。建议改为“首轮整体采用麦麦机制；本节复用核对基于 v1.4.7，实装版本与兼容性按任务记录”，避免实现者把研究快照误认成安装版本硬要求。
2. **低：修正一个拆分后失效的节号。** SPEC §5.5 末条仍写“记忆与人格的讨论顺序以 §0 最新记录为准”，明细没有 §0，主 PRD §0 也不再记录讨论顺序。建议直接改为“具体角色文案和正式界面按主 PRD §2.2、§4 的安排推进”。
3. 未发现第三项需要阻止本轮交付的问题；建议继续按已有待决项和任务逐项验证，不额外增加前置问答。
