# Momo 重构对话案例

讨论中出现值得以后试一遍的具体例子时，更新[案例册](references/cases.md)。先看是否已有同一场景。用户补充了时间、改口或澄清预期时，更新原例；需要比较两种条件时，在原例下加一个分支。

每例写明来源、按顺序发生的事、测试者要说或做什么，以及用户希望观察到的行为。尽量保留用户原话。为了让案例可回放而补的输入注明“回放输入”。探索中的想法可写成观察问题。示例只约束该场景，保留角色自然措辞的空间。

记录案例和修改需求文档是两件事。涉及麦麦已有能力时，先用相同输入试原版；只有实际差异才作为是否补做的依据。

回放时只给被测角色当轮可见的内容，预期留给测试者。跨天案例让角色看到相应的测试日期。按版本分别记录实际回复或动作、是否符合预期，以及差异出现在哪一轮。没有运行过的版本标为“待测”。
